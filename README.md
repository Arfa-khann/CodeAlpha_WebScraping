# Web Scraping Project

## Objective
The objective of this project is to extract data from a website and store it in a structured format for analysis.

## Tools Used
- Python
- Requests
- BeautifulSoup
- Pandas
- Excel

## Project Workflow
1. Access the target website.
2. Extract required data fields.
3. Clean and organize the data.
4. Save the extracted data into an Excel file.

## Output
The scraped data is stored in an Excel file for further analysis.

## Files Included
- task4.py
- scraped_data.xlsx
- README.md

## Conclusion
This project demonstrates how Python can be used to automatically collect and organize data from websites.
